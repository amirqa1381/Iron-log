🚀 راهنمای آوردن روی سرورهای ابری رایگان

شما می‌توانید اپلیکیشن Iron Log را با دیتابیس Supabase به صورت ۲۴ ساعته و کاملاً رایگان روی سرورهای ابری مستقر (Deploy) کنید:
گزینه ۱: Render.com (ساده‌ترین روش رایگان با GitHub)
  1. کد پروژه را در حساب GitHub خود Push کنید.
  2. وارد سایت render.com شده و ثبت‌نام رایگان کنید.
  3. روی New + کلیک کرده و گزینه Web Service را انتخاب نمایید.
  4. مخزن گیت‌هاب Iron-log خود را انتخاب کنید.
  5. تنظیمات را دقیقاً به این شکل بگذارید:
    • Environment: Node
    • Build Command: npm install && npm run build
    • Start Command: node server.ts (یا npm start)
  6. در تب Environment Variables متغیرهای زیر را وارد کنید:

گزینه ۲: استقرار با Docker در Railway یا Koyeb

فایل Dockerfile اختصاصی در ریشه پروژه قرار دارد. در پلتفرم‌های Railway یا Koyeb کافی است پروژه را از گیت‌هاب انتخاب کنید؛ به صورت خودکار کانتینر ساخته شده و با اضافه کردن متغیرهای فوق اجرا می‌شود.
